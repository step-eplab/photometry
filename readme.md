### Example of paths.json:

{\
"dir_raw": "/home/proj/data/",\
"dir_res": "/home/proj/results/",\
"catalog_path": "/home/proj/data/GRW.list"\
}

paths to directories with folders of nights (format: dd.mm.yy):
* dir_raw: with raw data
* dir_res: for results

and to GAIA catalog created by create_cat.py module in preparation package
* catalog_path
